# Visual Board Editor

Веб-приложение для работы с визуальными досками. API в dev эмулируется через MSW.

## Стек

React 19 · TypeScript · Vite · React Router 7 · TanStack Query · OpenAPI + MSW · Tailwind 4 · shadcn/ui · Zod · RHF

## Запуск

```bash
npm install
npm run dev
```

Тестовый пользователь: `admin@gmail.com` / `123456`

| Команда | |
|---------|--|
| `npm run dev` | Dev-сервер |
| `npm run build` | Сборка |
| `npm run api` | Регенерация типов из OpenAPI |
| `npm run lint` | ESLint |
